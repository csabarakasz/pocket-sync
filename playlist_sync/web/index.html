      Troubleshooting
      Playlist won’t load
      Make sure the Spotify playlist is public and paste its full share link.
      Music player doesn’t appear
      Check that it mounts in Finder. Select a folder on the player or enter its path manually.
      A download failed or matched the wrong recording
      Check Sync history or Activity & download details. Try Choose recording… to pick a different YouTube source.
      Request a feature

      Fill in this draft, then copy it into a new issue on the Pocket Sync GitHub repository. Keep private links and paths out of the draft.
