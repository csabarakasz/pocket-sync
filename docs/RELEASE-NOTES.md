# Pocket Sync source preview

Pocket Sync is a local Mac app for comparing a playlist with an existing music folder or mounted player. It includes manual recording selection, ordered YouTube playlist imports, per-library history, and in-app walkthroughs.

- See the README for setup and the screenshot gallery for a tour.
- This release includes GitHub’s source archives. A bundled Mac download is a separate release step.
- Automatic recording matches can choose a different version. Review results and use authorized audio sources.
